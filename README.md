A treasure map of the Isle of Crumbs, an island that does not exist — drawn
fresh by `main.py` in pure Python (standard library only, no dependencies).
Nine witty, legible place names (Port O' Pickles, the Giggling Grove,
Mt. Sneeze, Soggy Bay, Snailshell Shoals, the Weeping Palms, Gullible Gulch,
Cap'n Crumb's Cache, and X Marks the Spot), a dotted route from the landing
cove to a marked X, a compass rose, a very polite kraken, and a small
galleon, all in one consistent parchment-and-ink style. Deterministic: the
same seed always draws the same map.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
# writes /tmp/out/entry.png (1024x1024, well under the 1 MiB gate)
```
